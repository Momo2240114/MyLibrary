4. 過去制作：既存ページを維持。ANATHEMAとは別の担当実績として扱い、ACCEL TRAILの人数や担当は今回創作しない。

詳しい技術説明は既存作品ページの折りたたみテキストに収める。ページが長くなる場合だけ「技術詳細」を追加し、4件の本文を移す。移動先ができる前に空リンクを作らない。
