# Google Sitesへの反映手順と公開前作業

## 今回の成果物の使い方

1. Preview.htmlで画像と文章の優先順を確認する。Google Sitesの完成画面そのものではなく、配置を確認するローカルプレビュー。
2. 01で変更理由を確認する。
3. 02の各「掲載本文」を既存Google Sitesへ貼り付ける。「編集指定」「掲載本文ここまで」、素材ID、根拠一覧は公開しない。
4. 03の対応表で既存画像を挿入し、未撮影の場所は素材が揃うまで画像枠や再生ボタンを置かない。
5. 04で面接時にコードと説明をたどれるようにする。

Google Sitesの編集画面は今回操作していない。公開サイトとローカルコードから、先に内容をレビューできる原稿・手順・プレビューを作成した。ログイン権限や自動保存された下書きの有無は未確認。直接編集が不可能と断定したものではない。

## Google Sitesでの配置の目安

- PCは本文最大幅を統一する。ゲーム画面とメイン動画は、テキスト列より広く見せる。画面に文章を重ねず、下に短いキャプションを置く。
- 最初の画面に大きな「就職作品について」と注意書きだけを置かない。作品名・ゲームの1文・戦闘画面を優先する。
- 2形態は2列レイアウトを使い、画像の比率と文字量をそろえる。各画像を小さなサムネイルにしない。
- 技術の要約は2～3文を基本にする。詳細は「折りたたみ可能なテキスト」にC1～C4を配置する。初期状態で長文を全部開かない。
- 説明図は同梱PNGを「画像」から挿入する。画面幅に合わせて拡大し、文字が小さければ1段ずつの縦並びへ置き換える。
- YouTubeは「挿入→YouTube」から既存V00を指定する。新動画のURLは収録・アップロード後に置き換える。自動再生は前提にしない。
- ボタン名は「こちら」より「ゲームと実装の工夫を見る」「開発状況を見る」のように、移動先が分かる名前にする。
- スマートフォン用プレビューで、2列が自然に縦に並ぶこと、画像・字幕・図の文字を読めることを確認する。
