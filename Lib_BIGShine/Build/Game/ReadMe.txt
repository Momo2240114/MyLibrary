ANATHEMA — 忌まわしき影
アナテマ
作品講評会用 操作ガイド
========================================

【作品について】
ボスとの戦闘を中心にした3Dアクションゲームです。
攻撃・回避・ガード・パリィと4種類のスキルを使用します。

【起動・終了】
1. 配布フォルダー全体を展開してください。
2. ANATHEMA.exeをダブルクリックしてください。
   EditorのExport Game機能で作成された配布物では、Game.exeを起動してください。
3. タイトル画面でGAME STARTを選ぶと、ロード画面を経由して本編が始まります。

【タイトル操作】
選択：上下キー／方向パッド上下／左スティック上下／マウス移動
決定：Enter／Xbox A／PlayStation ×／左クリック
TUTORIALとSETTINGSは準備中のため選択できません。
EXITを選ぶと終了します。

終了：Escキー、またはウィンドウの閉じるボタン
全画面／ウィンドウ切り替え：Alt + Enter
最初から遊び直す場合：終了して同じ実行ファイルを起動し直してください。

ANATHEMA.exe（Export Game版ではGame.exe）、GamePackage.json、Dataフォルダー、同梱DLLは同じ場所に置いてください。
実行ファイルだけを移動すると、必要なデータを読み込めません。

スキルはL1／LBを押し続けた状態で、各ボタンを押してください。
通常のジャンプはL1／LBを離してから×／Aを押してください。

【遊び方のポイント】
・まず移動、左クリック／□／Xの攻撃、回避を試してください。
・敵の攻撃に合わせてガードやパリィを使い、攻撃の機会を作ってください。
・HealはHPを25回復します。使用後は30秒のクールタイムがあります。
・HUDに操作ガイドとスキルの残りクールタイムを表示します。
・演出中や行動中など、入力を受け付けない場合があります。
・操作ガイドは使用中の入力機器や設定によって切り替わります。

【動作環境】
Windows向け64bit版です。DirectX 11を使用します。
必要なGPU・メモリ容量、個別コントローラーでの動作は配布前の確認対象です。
このガイドは標準の入力設定・スキル装備を説明しています。
設定や装備を変更した配布物では、ゲーム内のHUD表示を参照してください。
